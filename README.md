


# Описание проекта

Этот проект реализует RAG (Retrieval-Augmented Generation) пайплайн, предназначенный для работы с конкретным текстом из статьи "Иллюзия качества: ваш сайт идеален? Поздравляем, вы только что сожгли бюджет".

Пайплайн включает в себя все ключевые этапы обработки данных и генерации ответов:

- Сбор и предобработка данных: Загрузка текста со страницы, его очистка и разделение на чанки.
- Векторизация: Преобразование текстовых чанков в числовые векторы.
- Индексация: Загрузка векторов в векторную базу данных Qdrant.
- Генерация ответа: Поиск наиболее релевантных чанков по запросу пользователя и использование их для генерации ответа с помощью LLM.

Проект упакован в Docker для обеспечения воспроизводимости, а для отслеживания экспериментов используется MLflow.

# Как запустить проект

1. Предварительные требования

- Установите Docker и Docker Compose.
- Установите Git для клонирования репозитория.
- Получите API-ключ Groq для использования LLM. Создайте файл .env в директории app и добавьте в него свой ключ:
- API_KEY=ваш_ключ_groq

2. Запуск сервисов

В корневой директории проекта выполните команду:
```bash

docker-compose up -d
```
Эта команда запустит три сервиса в фоновом режиме:

    qdrant — векторная база данных.

    mlflow — сервер для отслеживания экспериментов.

    notebook — контейнер с Jupyter Notebook.

3. Запуск пайплайна в Jupyter Notebook

Jupyter Notebook — это ключевой элемент проекта. Он предоставляет интерактивную среду, где вы можете пошагово выполнять весь RAG-пайплайн, отслеживать результаты и проводить отладку.

- Откройте браузер и перейдите по адресу: http://localhost:8888.

- В файловом менеджере Jupyter перейдите в директорию app.

- Откройте файл rag_pipeline.ipynb.

- Запустите, чтобы увидеть, как пайплайн обрабатывает данные и генерирует ответ.

4. Проверка работы

После выполнения всех ячеек в блокноте:

- Ответ на вопрос: В последней ячейке вы увидите ответ на вопрос "Что автор имеет в виду под 'иллюзией качества'?", сгенерированный LLM на основе информации из статьи.
- Логи и артефакты: Проверьте директории app/artifacts и app/logs на наличие сгенерированных файлов (.txt, .jsonl, .json).
- Мониторинг: Откройте http://localhost:5000 в браузере, чтобы просмотреть логи MLflow, включая параметры запуска и сохраненные артефакты.
